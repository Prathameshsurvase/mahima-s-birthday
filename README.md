# 🎀 React Birthday Surprise Web App 💖

Built with **React + Vite + Framer Motion**!

## ✨ Features
- **Framer Motion spring animations**: 3D Wax-sealed interactive envelope, runaway "No" button, 3D flip polaroids, tone arm transitions, and bouncing Pip the cat.
- **Fully Responsive**: Expands into a beautiful 1100px wide scrapbook layout on Desktop / Tablet (with multi-column grids) and collapses into a touch-optimized mobile experience for her phone.
- **Interactive Experiences**:
  1. Interactive Envelope with slide-out letter
  2. "Are you ready?" quiz with dodging button & sassy cat popup (*"HOW DARE YOU!? 😾"*)
  3. 3D Strawberry Birthday Cake with blowable candle & confetti shower
  4. Vintage Vinyl player with synthesized Web Audio API music box tune
  5. 3D Flip Polaroids with custom photo upload
  6. Pip the Cat compliment machine & live love meter
  7. Interactive Shimmer Scratch Card
  8. "Will you be my date tonight?" & VIP Date Night Boarding Pass
  9. Discreet `✏️ Personalize` tool to customize her real name, nickname, and date location

## 🚀 How to Run

### Development Mode:
```powershell
cd birthday-surprise-react
npm run dev
```
Open `http://localhost:5173` in your browser!

### Production Build:
```powershell
npm run build
```
The built files are in the `dist` folder. You can drag and drop the `dist` folder directly onto [Netlify Drop](https://app.netlify.com/drop) or deploy via Vercel to get a live URL to send to her phone!
